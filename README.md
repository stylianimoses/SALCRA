A modernised frontend web redesign for the **Sarawak Land Consolidation and Rehabilitation Authority (SALCRA)**, developed during my **Web Developer Internship**. This project focuses on revamping SALCRA's digital portal to enhance user experience and modernise branding, including SALCRA's 50th Anniversary.

---

## 📌 Project Overview

The main objective of this repository is to transform SALCRA's web presence into a responsive, fast, and visually compelling platform. It features clean UI architecture, structured navigation, and optimised layouts tailored for desktop, tablet, and mobile users.

## 🔑 Key Highlights
* **Modernised Visual Identity:** Clean layouts, impactful hero sections, and updated brand styling.
* **Responsive Layout:** Fully flexible design that adapts seamlessly across mobile, tablet, and desktop screens.
* **Clean Frontend Structure:** Well-organised template structure styled with CSS3 and Tailwind CSS for rapid and modern design execution.

---

## 🛠️ Tech Stack & Tools

* **Frontend:** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS
* **Design & Wireframing:** Figma, Canva
* **Coding Platform:** Visual Studio Code (VSC), Google Antigravity
* **Hosting & Deployment:** Vercel
* **Version Control:** Git & GitHub

As a **Web Developer Intern**, my primary responsibilities in this project included:
